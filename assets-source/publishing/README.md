# Project listing icon

`project-icon.png` is the original square icon generated on 2026-11-16 with Codex's built-in `image_gen` tool for the Modrinth and CurseForge project pages. The user requested an Arrow 4D car and X2-logo inspiration; this revision replaces the first draft's vertical-axis spinner. It uses an original 4D mark, four outboard seats on transverse axles, and four foreground rails. It is covered by the repository's CC0-1.0 license. It is not an upstream dependency or manufacturer asset.

Initial draft prompt (superseded by the Arrow revision in `arrow-icon-prompt.txt`):

> Use case: logo-brand. Asset type: square project icon for Coasters: Fourth Dimension, a Minecraft roller coaster mod. Create a crisp original icon: bold readable '4D' monogram integrated with a stylized looping steel roller-coaster track and a small blocky rotating-seat coaster car. Clean dimensional voxel-inspired geometry, restrained mechanical detail, strong contrast and simple silhouette readable at 64px. Centered composition with generous margins on a solid dark background. Exact text: '4D'. No other words, no manufacturer or Minecraft or Create logos, no watermarks. Square PNG, at least 400 by 400.
