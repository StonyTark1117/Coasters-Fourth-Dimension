# FD401C selected-JAR combined wired Arrow circuit

This bundle records a bounded powered ride on the exact clean selected JAR, SHA-256 `656725bcbacc8f491de274c6c058027d0aaa67cfc6f893ba6d7e4a9eb24abbc7`, with Track Styles 1.2.0 and Engineered 1.1.1 loaded together. The run used Java 21.0.13, private Xvfb `:277`, a 1536M game heap and an active systemd scope capped at 3G. The client saved and exited normally; the scope reported `Result=success`.

The world starts from the preserved input checkpoint in [input-world.tar.gz](input-world.tar.gz). Engineered `requireEnergy=true`; the native wired anchor began at 100,000 FE, with the Create alternator at 8 RPM, capacity 768 and stress 512. The rider boarded an actual Arrow seat by empty-hand right-click after F3 showed `fourthdimension:arrow_seat`; restraints were closed in the normal Rotation Tool UI. The [screenshots](screenshots/) show the board, F3 seat target, restraint state, ride and final title screen. One validation-only board/dismount was used to identify the seat; its `FD_BOARDING_DISMOUNT_CLEAR` event is logged, and the accepted ride boarding was a later normal right-click.

After releasing the station signal and pulsing the linked controller, the occupied car moved from approximately `(-467.5, 143.1, -629)` and returned to `(-499.5, 143.1, -617.5)`. Restoring the station signal brought it to `capture=true` at about 0.0009 blocks/s. Anchor FE fell to 94,355. The controller recorded `PassReached=19.4069/20` and `PassShort=1`: this proves the train completed the geographic circuit and station capture, but missed its programmed speed target. The UI still reported `Ready | Restraints closed`; restraints were opened through the UI and Shift-dismount cleared the rider. Final validation reported `assignments=0`, and `RootVehicle` was absent.

A second trigger attempt did not leave the station and never entered `Starving`. The source audit found that the first removal had left a second water wheel at `(-507,142,-635)` active; both original north-facing wheels were restored, and the alternator returned to 8 RPM / 768 capacity. The world was saved with the rider cleared. This attempt is recorded for diagnosis only.

This bundle does **not** prove a full circuit after FE starvation and restoration, a pass that reaches 20/20, a current-source client run, a cold reopen, or fresh route construction. The prior [selected-JAR FE interruption result](../fd401-combined-wired-fe-recovery-selected-20261105/README.md) remains the bounded proof of starvation, wired restoration, short resume and manual capture/unload; its own `PassShort` limitation remains open.

`client-console.log.gz` retains the full log and `commands.txt` records every command plus the explicit manual click. `final-world.tar.gz` is the cleanly exited saved world. The exact selected JAR and dependency hashes are retained in the qualification bundle and [dependencies.sha256](dependencies.sha256). Run `sha256sum -c SHA256SUMS` from this directory and `sha256sum -c selected-jar.sha256` from this directory to verify the evidence files and selected artifact.
