# FD401C clean-JAR Legacy helper setup, interrupted before operation

On 2026-11-05, a Java 21 client loaded the selected clean committed-source `ec2fcda` JAR (SHA-256 `656725bcbacc8f491de274c6c058027d0aaa67cfc6f893ba6d7e4a9eb24abbc7`) with Styles 1.2.0 and Engineered 1.1.1, in a copy of the [four-family construction world](../fd401-engineered-current-combined-construction/README.md). The client used task-owned Xvfb `:242`, `-Xmx1024M`, and active `run-p328131-i325879.scope` with `MemoryMax=3221225472`. Host available memory was about 32 GiB before launch. The [launch](run-client.sh), [commands](commands.txt), [console](console.log.gz), and [game log](game.log.gz) are retained.

The global `/fd validation board_locked Dev` helper first boarded an older Arrow car and closed its restraints. `/ride Dev dismount` reported success but did **not** clear the guarded rider assignment; repeated `FD_BOARDING_DISMOUNT_CANCEL` entries followed. Teleporting did not move the player away from that seat. A disclosed `/forceload add 300 120 300 160` loaded the fresh Legacy route, raising live availability from one to two loaded chassis. A second helper call then mounted Dev on the Legacy carrier at about `(303.5,184.4,130.8)` and logged `FD_BOARDING_ASSIGN ... accepted=true` with one assignment. The [first](first-board.png) and [Legacy](legacy-helper-board.png) screenshots distinguish these mounts. A fixture command initialized `CoastersEngineeredEnergy=100000` on `(300,183,120)` and the saved controller at `(290,183,121)` reported `Launch 20 → Stop 12 → End` ([screenshot](legacy-fe-program.png)).

Before any controller pulse, the private `:242` Xvfb process exited and the client logged `X connection to :242 broken`. The client scope later became inactive with `Result=success`, but this was **not a normal Save and Quit**. The reason the display ended was not established; the host had memory headroom and no scope OOM was observed. The copied working world remains at `/tmp/fd401c-clean-combined-operator3/game/saves/FD401Stop12`; the untouched source world remains in the linked construction bundle.

This is **setup evidence only**. It proves neither normal seat-click boarding nor launch, STOP, station capture, or unload on the clean combined profile. It should not be used as an FD401C operator pass. The repeated dismount cancellation also makes this particular working copy unsuitable for further acceptance without restoring a clean world.
