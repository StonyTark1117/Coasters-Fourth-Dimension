# FD403 Ponder checkpoint — 0.9.0-dev.10

This is a teaching-content checkpoint, not the 0.4 gate or the 0.9 release
candidate. Complete survival acquisition/building/operation exercises remain
open. The original resource-reload crash remains unresolved.

## Shipped content

Nine original schematics and storyboards cover functional family matching,
anchor construction, driven Arrow carriers, legacy free carriers, four Free
Spin pairs, revised lower hinges, magnetic spans, station interlocks and the
PAX catch/lift/release/return cycle. All fifteen craftable items expose Ponder
through the normal inventory shortcut, for 53 item/scene registrations. There
are nine translated titles and 53 captions. The source text and deterministic
resource generator are `scripts/ponder-lessons.json` and
`scripts/generate-ponder.py`; generated English defaults live in
`PonderLessons.java`.

Schematics use original geometry, the addon's own blocks and blocks resolved
from installed Minecraft/Coasters. They contain no copied external schematics,
models or textures. Colored strips and the compact shuttle route are explicitly
diagrams. Ponder animations explain the controls and sequence; they are not
Sable physics, wheel-clearance certificates or exact manufacturer spin models.
The separate native and packaged ride records remain the mechanics evidence.

The physical client registers the plugin against installed Ponder
`1.0.82+mc1.21.1`, already supplied by Create. Exact primary API sources were
inspected from its published sources JAR. Dedicated-server code does not load
client Ponder classes. The ordinary client does not run the opt-in playback
validator.

## Native and packaged validation

The final Java 21 build passes. All 25 unit tests have zero failures, errors or
skips. Standalone and combined Track Styles/Engineered runs each pass all 27
required native tests. The new native resource test uses Minecraft's NBT decoder
and loaded block registry to check nine schematics, 1968 placed blocks, valid
state properties/palette indices/bounds, unique positions and the five-family
seat counts. Existing crafting/discovery and ride regressions still pass.

The final standalone client loads the packaged JAR identified in
[artifact digest](ponder-artifact.sha256). Its opt-in validator compiles, plays
to completion and restores/replays every one of the 53 registrations, verifies
English titles/captions and checks all nine scenes are reachable. This passes
at startup and again after an actual F3+T reload completes. Normal hold-W access
and next-scene controls render all nine unique scenes, including all five family
items. The screenshots record representative frames and readable captions,
not a complete video of every instruction. Complete playback/replay is recorded
separately by the client trace.

An initial rendered review exposed captions overlapping the bottom buttons in
the 854×480 window. The final version uses a fixed caption position and a smaller
diagram view. [Initial overlap](ponder-initial-caption-overlap.png) and
[corrected station caption](ponder-boarding.png) distinguish those iterations;
only the final artifact is accepted here.

The final reload started at 02:09:42 MST on 2026-10-01; the second complete
playback/replay pass is logged at 02:09:47. Ponder rendering continued through
the remaining family lessons. The world was saved, reopened through the normal
world list, and native command suggestions rendered with `/da`; the read-only
`/data get entity @s SelectedItem` query then completed. An earlier too-fast input
lost its initial characters and submitted local chat instead; that attempt is
not command-execution evidence. Normal Save and Quit, then Quit Game, ended the
final process with exit code zero. No occupied ride was attempted.
