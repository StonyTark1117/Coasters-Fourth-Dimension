**1.0.0 Beta** release for Minecraft **1.21.1 / NeoForge 21.1.256**.

- 17 coaster vehicle styles with matching functional track and native seat motion.
- Controlled/free rotation, shuttle mechanisms, suspended/inverted and flying rides, dive holds, boarding/restraint controls, saved programs, recovery tools, and Ponder tutorials.
- Requires Create 6.0.10, Create: Coasters Simulated 0.1.5, and Sable 2.0.6 with their support libraries.
- CC0-1.0 license is included in the JAR and mod metadata.

Install matching builds on clients and servers. Back up existing worlds before upgrading. See the project description and linked guides for operating and compatibility limits.

Promoted from Alpha to Beta after reconciliation of the completed FD901–FD905 gates. The JAR, version number, dependencies, and support limits are unchanged.
