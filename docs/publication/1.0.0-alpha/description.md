# Coasters: Fourth Dimension

Build roller coasters whose seats do more than follow the track. Fourth Dimension adds **17 vehicle styles** to **Create: Coasters Simulated**, with matching functional track, native moving seats and mechanisms, station and restraint controls, saved ride programs, and Ponder tutorials.

## Ride styles

- **Controlled and free rotation:** Arrow controlled, Legacy ZacSpin, S&S-inspired Free Spin, and Revised ZacSpin.
- **Shuttles and spinning rides:** PAX-inspired shuttle, S1 Spinning, S2 Spinning, Axis, and Roller Ball.
- **Above, beside, and below the track:** Wing, Suspended, Fixed Inverted, Pipeline, Dive, and Powered Inverted Yaw.
- **Flying postures:** Conventional Flying and New-generation Flying, including physical seated/prone transitions.

Program seat rotation, operate boarding and restraints, and use each family's physical mechanisms and recovery tools. A separate local comfort option can stabilize your camera while preserving native rider motion.

## Install 1.0.0 Alpha

This initial public upload is marked **Alpha**. Install the same Fourth Dimension build on every client and server.

- Minecraft **1.21.1** and **Java 21**
- NeoForge **21.1.256**
- Create **6.0.10**
- Create: Coasters Simulated **0.1.5**
- Sable **2.0.6**, with the support libraries supplied by the dependency stack (Sable Companion **1.6.0**, Veil **4.3.2**, and Flywheel **1.0.6**)

Install dependencies separately; their code and art are not bundled in Fourth Dimension. Optional coaster addons are not required for standalone Fourth Dimension rides. This version targets NeoForge, not Fabric or Forge.

## Start building

Use the Fourth Dimension creative tab or crafting recipes, connect Coasters anchorpoints with matching track, and place the correct car. Configure rotation where applicable, bind a Boarding Station, close restraints, and dispatch. Each family has its own track, coupling, drive, clearance, and recovery rules.

## Compatibility and limits

Build within **1,024 blocks horizontally of world origin**. Per-dimension limits are 256 sections, 64 vehicles, 8,192 profile keys, and 512 magnetic spans. These are correctness limits, not performance guarantees. Matching appearance alone does not make external track or vehicles functionally compatible.

Back up existing worlds and test upgrades on a copy. Keep client and server versions matched, and do not downgrade upgraded worlds in place. Repairing a fault does not automatically restart a ride; use the documented recovery procedure.

[Backup and migration](https://github.com/StonyTark1117/Coasters-Fourth-Dimension/blob/main/docs/MIGRATION.md) · [Optional integrations and support boundaries](https://github.com/StonyTark1117/Coasters-Fourth-Dimension#optional-integrations)

These rides are independently authored game interpretations inspired by coaster concepts. Manufacturer names do not imply endorsement, exact engineering, or manufacturer-provided assets.
